Get Meaningful Column Names

How long column names get shortened, and why AI makes the result better

AI shortening is recommended.
A CSV column can only be so many characters long in a database. Without AI, long names get shortened using mechanical rules that lose meaning. With a free Gemini API key connected, the app understands what a column actually means and shortens it while keeping it readable.
1 Why AI is recommended
  • AI reads the column name the way a person would and keeps the words that actually carry meaning.
  • Without it, names are shortened mechanically — still safe and unique, but harder to recognize later.
  • Google AI Studio's Gemini API has a free tier, so this costs nothing to set up.
  • If no key is set, the app still works — it just skips straight to the mechanical steps below.
2 Create a free Gemini API key
  • Go to Google AI Studio and sign in with any Google account.
  • Click "Create API key", then choose or create a Google Cloud project when prompted.
  • Copy the key that's generated — it's a long string starting with AIza....
Open Google AI Studio
3 Store the key as a system environment variable
  • The app reads the key from a variable named GEMINI_API_KEY — it is never typed into this page.
  • Windows (Command Prompt, run once): setx GEMINI_API_KEY "your-key-here" Close and reopen any terminal / IDE afterwards so it picks up the change.
  • macOS / Linux (add to your shell profile, e.g. ~/.bashrc or ~/.zshrc): export GEMINI_API_KEY="your-key-here" Then restart the terminal or run source ~/.bashrc.
  • Restart this application after setting the variable — it's only read once, at startup.
4 Example: one long column name, two paths

Original column name (146 characters):

the_total_number_of_monthly_active_premium_customer_accounts_created_during_the_previous_fiscal_reporting_period_across_all_regional_business_units_and_departments

With AI (understands the meaning)

AI (Gemini)
mthly_actv_prem_cust_accts_prev_fy_rpt_period

Without AI (mechanical stages, in order)

1. NLP
tot_num_cust_acct
Keeps only meaningful words (nouns), drops filler words, then abbreviates known business terms.
2. Vowel Removal
tt_nm_cstmr_acct
Only used if step 1 is still too long. Strips inner vowels, keeps the first letter of each word.
3. Hash Fallback
tt_nm_cstmr_a91f
Last resort, only if still too long or not unique. Trims the name and adds a short unique code.

Every column gets a name — with AI enabled, most real column names are handled at the first, most readable stage. A full mapping of original → final names is always saved for you to review.
